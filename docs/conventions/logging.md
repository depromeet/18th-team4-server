# 로깅 규칙

> 적용 대상: 로그를 남길 때 레벨을 정하고 메시지를 작성할 때.

## 로그 레벨

| 레벨 | 용도 | 예시 |
|------|------|------|
| ERROR | 즉시 대응이 필요한 장애 | 외부 API 실패, DB 연결 실패 |
| WARN | 잠재적 문제 | 재시도 성공, 폴백 동작 |
| INFO | 주요 비즈니스 흐름, 입출력 | 사용자 가입, 주문 생성 |
| DEBUG | 개발 디버깅 용도 | 운영 환경에서는 비활성화 |

## 로그 메시지 작성

- 로그 메시지는 한글로 쓰되 Token Pair / Access Token / Rate Limit / Stream 같은 기술 용어는 영문을 유지한다. 억지로 번역하지 않는다.

> 예외를 잡거나 던지는 지점에서 어느 레벨로 남길지의 상세 기준은 [exception-handling.md](exception-handling.md) "예외 발생 지점의 로그 레벨" 절 참조.
