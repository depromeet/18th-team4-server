# 작업 절차

AI 가 이 저장소에서 작업을 수행할 때 지켜야 할 지시와 기본 작업 순서.

## 지켜야 할 지시

절대 규칙 3개(CLAUDE.md 임의 수정 금지 / 지시된 파일만 생성·수정 / 임의 삭제 금지)의 원본은 루트 [CLAUDE.md](../../CLAUDE.md) 의 "⚠️ 작업 지시" 절이다. 작업 시작 전 그대로 따른다.

## 기본 작업 순서

현재 팀 관행을 정리한 순서다. 각 단계는 이미 저장소에 있는 규칙·참조 구현체를 따른다.

1. **관련 문서 확인** — `docs/conventions/` 에서 해당 규칙을 찾고, `docs/domain/README.md` 로 도메인 위치를 파악한다.
2. **관련 코드 탐색** — 각 계층의 `example/` 하위 참조 구현체를 참고해 어디에 무엇을 두는지 확인한다.
3. **구현 + 테스트 작성** — 서비스 레이어는 단위 테스트를 반드시 작성하고, 조회 기능은 DAO 통합 테스트를 반드시 작성한다 (상세는 `docs/conventions/testing.md`).
4. **테스트 실행** — `./gradlew test` 로 전체 테스트를 돌린다.
5. **잔존물 확인** — `/verify` 체크리스트로 남은 것을 점검한다: TODO 잔존 여부, 전체 테스트 통과 여부, domain/presentation 계층의 `@Value` 사용 여부, Service/Repository 에 대응하는 테스트 클래스 존재 여부.
6. **변경 요약 보고** — 무엇을 왜 바꿨는지 요약해 보고한다.
